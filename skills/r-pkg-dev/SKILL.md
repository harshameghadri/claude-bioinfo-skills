# R Package Development Skill

Complete workflow for building a professional, portfolio-ready R package with
Roxygen2 documentation, renv reproducibility, and modular function design.
Written for Bioconductor/CRAN-style bioinformatics packages (examples use a hypothetical spatial GSEA package, `mypkg`).

---

## Package Structure

```
mypkg/
├── DESCRIPTION               ← Package metadata and dependencies
├── NAMESPACE                 ← Auto-generated by roxygen2 — never edit manually
├── R/
│   ├── load_visium.R         ← One logical unit per file
│   ├── qc_metrics.R
│   ├── spatial_gsea.R
│   └── utils.R               ← Internal helpers (not exported)
├── man/                      ← Auto-generated by roxygen2
├── tests/
│   └── testthat/
├── vignettes/
│   └── spatial-gsea-intro.Rmd
├── inst/
│   └── extdata/              ← Small example datasets
├── renv/                     ← Managed by renv
├── renv.lock                 ← Dependency lockfile — commit this!
└── .Rprofile                 ← Sources renv/activate.R automatically
```

## Step 1 — Initialise the Package

```r
# One-time setup — run from project root in RStudio or R console
install.packages(c("devtools", "usethis", "roxygen2", "testthat", "renv"))

# Create package scaffold
usethis::create_package("mypkg")   # creates directory + DESCRIPTION + R/

# Inside the new package project:
usethis::use_roxygen_md()      # enable Markdown in Roxygen2 docs
usethis::use_testthat()        # initialise tests/
usethis::use_vignette("spatial-gsea-intro")  # vignette scaffold
usethis::use_git()             # initialise git repo
usethis::use_github_actions()  # CI/CD with R CMD check
```

## Step 3 — Roxygen2 Function Template

**Master template** — copy and adapt for every exported function:

```r
#' Load and Validate Visium HD Data
#'
#' Loads a 10X Genomics Visium HD spatial transcriptomics dataset from a
#' standard output directory and performs basic structural validation.
#'
#' @param data_dir `character(1)`. Path to the `square_016um` output directory
#'   produced by Space Ranger.
#' @param assay `character(1)`. Name to assign to the Spatial assay.
#'   Default: `"Spatial"`.
#' @param image_name `character(1)`. Filename of the tissue image inside the
#'   `spatial/` subdirectory. Default: `"tissue_lowres_image.png"`.
#' @param verbose `logical(1)`. Print progress messages. Default: `TRUE`.
#'
#' @return A [Seurat::Seurat-class] object with the Spatial assay populated
#'   and the tissue image attached.
#'
#' @details
#' This function wraps [Seurat::Load10X_Spatial()] with additional validation
#' steps appropriate for Visium HD data:
#'
#' - Checks that the `filtered_feature_bc_matrix.h5` file exists
#' - Checks the `spatial/` subdirectory is present
#' - Reports spot and gene counts on success
#'
#' @examples
#' \dontrun{
#' obj <- load_visium_hd(
#'   data_dir = "data/raw/.../square_016um",
#'   verbose  = TRUE
#' )
#' }
#'
#' @seealso [compute_qc_metrics()], [filter_spots()]
#'
#' @importFrom Seurat Load10X_Spatial Read10X_Image
#' @export
load_visium_hd <- function(data_dir,
                            assay      = "Spatial",
                            image_name = "tissue_lowres_image.png",
                            verbose    = TRUE) {

  # Input validation
  if (!dir.exists(data_dir)) {
    stop("`data_dir` does not exist: ", data_dir, call. = FALSE)
  }

  h5_file <- file.path(data_dir, "filtered_feature_bc_matrix.h5")
  if (!file.exists(h5_file)) {
    stop("Cannot find filtered_feature_bc_matrix.h5 in: ", data_dir, call. = FALSE)
  }

  if (verbose) message("Loading Visium HD data from: ", data_dir)

  obj <- Seurat::Load10X_Spatial(
    data.dir  = data_dir,
    filename  = "filtered_feature_bc_matrix.h5",
    assay     = assay,
    image     = Seurat::Read10X_Image(
      image.dir  = file.path(data_dir, "spatial"),
      image.name = image_name
    )
  )

  if (verbose) {
    message("Loaded: ", ncol(obj), " spots × ", nrow(obj), " genes")
  }

  obj
}
```

### Internal (non-exported) helper template

```r
#' Validate a Seurat Spatial Object
#'
#' @param obj A Seurat object. Must have a Spatial assay.
#' @param assay `character(1)`. Assay to check. Default: `"Spatial"`.
#'
#' @return Invisibly returns `obj` if valid. Stops with an informative
#'   error if validation fails.
#'
#' @keywords internal
.validate_spatial_seurat <- function(obj, assay = "Spatial") {
  if (!inherits(obj, "Seurat")) {
    stop("`obj` must be a Seurat object.", call. = FALSE)
  }
  if (!assay %in% Seurat::Assays(obj)) {
    stop("Assay '", assay, "' not found in object.", call. = FALSE)
  }
  invisible(obj)
}
```

> **Convention**: prefix internal functions with `.` (dot). They are not exported
> and not documented in the public manual. `@keywords internal` suppresses
> their appearance in `?` help.

## Step 4 — Document and Build

```r
# Run this after every change to Roxygen2 comments
devtools::document()          # regenerates man/ and NAMESPACE

# Load the package interactively (no install needed)
devtools::load_all()          # equivalent to library(mypkg)

# Run R CMD CHECK — catches issues before pushing to GitHub
devtools::check()

# Build a source tarball
devtools::build()
```

**Development loop:**
```
Edit R/*.R → devtools::document() → devtools::load_all() → test interactively → repeat
```

## Step 5 — renv Environment Management

```r
# Initialise renv (run once, inside the package project)
renv::init()

# After installing/updating any packages:
renv::snapshot()              # writes/updates renv.lock

# Restore exact environment from lockfile (e.g., on a new machine or CI)
renv::restore()

# Check for outdated packages
renv::status()

# Update a specific package and snapshot
renv::update("Seurat")
renv::snapshot()
```

> **Git workflow**: Commit `renv.lock` with every `snapshot()`. Never commit
> `renv/library/` — it belongs in `.gitignore`.

## Step 6 — Writing Tests with testthat

```r
# Create a test file (mirrors your R/ file name)
usethis::use_test("load_visium")   # creates tests/testthat/test-load_visium.R
```

```r
# tests/testthat/test-load_visium.R

test_that("load_visium_hd stops on missing directory", {
  expect_error(
    load_visium_hd("nonexistent/path"),
    regexp = "does not exist"
  )
})

test_that("load_visium_hd returns a Seurat object", {
  skip_if_not(file.exists("inst/extdata/test_visium/"), "Test data not available")

  obj <- load_visium_hd("inst/extdata/test_visium/")
  expect_s4_class(obj, "Seurat")
  expect_true("Spatial" %in% Seurat::Assays(obj))
})
```

```r
# Run all tests
devtools::test()

# Run a single test file
testthat::test_file("tests/testthat/test-load_visium.R")
```

## Roxygen2 Tag Cheat Sheet

| Tag               | Purpose                                              |
|-------------------|------------------------------------------------------|
| `@param`          | Document a function argument                         |
| `@return`         | Describe the return value                            |
| `@export`         | Add function to NAMESPACE (make it public)           |
| `@importFrom`     | Import specific function: `@importFrom pkg fun`      |
| `@examples`       | Runnable examples (tested by `devtools::check()`)    |
| `\dontrun{}`      | Examples that don't run during `R CMD CHECK`         |
| `@seealso`        | Link to related functions                            |
| `@keywords internal` | Mark as internal — skipped in public docs         |
| `@family`         | Group related functions in documentation             |
| `@section`        | Add a named section to the help page                 |
